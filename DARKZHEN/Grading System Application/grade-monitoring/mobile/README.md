# Student mobile app (Flutter)

Read-only grade viewer. Requires the [Flutter SDK](https://docs.flutter.dev/get-started/install) (not installed on the dev machine yet).

## First run

The `android/` platform folder is generated by Flutter on demand:

```powershell
flutter create . --org ph.sagaynhs --project-name grade_monitoring_mobile
flutter pub get
```

## Run against the local backend

The emulator reaches the host machine at `10.0.2.2`, which is the default base URL:

```powershell
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

For a physical device on the same Wi-Fi, use your PC's IP address instead:

```powershell
flutter run --dart-define=API_BASE_URL=http://192.168.x.x:8000
```

## Structure (per architecture document, section 5.1)

- `lib/domain/` - plain models, no computation
- `lib/data/` - API client, token handling, secure storage (refresh token in `flutter_secure_storage`, access token in memory)
- `lib/core/` - session state (`AppState` via provider), session-expiry events
- `lib/features/` - screens: login, change password, dashboard (subject grades per semester + general average), profile

Access-token expiry is handled silently via `/auth/refresh/`; if the refresh token fails, the app returns to the login screen.
