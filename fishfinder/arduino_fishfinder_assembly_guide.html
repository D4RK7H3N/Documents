1
Install Arduino libraries
Open Arduino IDE. Go to Sketch → Include Library → Manage Libraries. Search and install: Adafruit GFX Library, Adafruit ILI9341, and NewPing.
2
Set up the breadboard
Place the Arduino and breadboard side by side. Connect the breadboard power rail: Arduino 5V → red rail, Arduino GND → blue rail. This gives you shared power and ground for all components.
3
Wire the TFT display
Connect all 8 TFT pins using the wiring table. Use the SPI pins (11, 13) for MOSI/SCK. Connect TFT LED/backlight to 3.3V through a 100Ω resistor to limit current and protect the LED.
4
Wire the JSN-SR04T sonar
Connect VCC to 5V, GND to GND, TRIG to Pin 6, ECHO to Pin 7. Route the sonar cable through a hole in your project box so the transducer hangs outside, facing downward into the water.
5
Wire the optional buzzer
Connect buzzer positive (+) to Pin 4, negative (−) to GND. The passive buzzer will beep when fish are detected. If no buzzer, no changes needed — the code handles it gracefully.
6
Upload the code
Connect Arduino to PC via USB. Select Board: Arduino UNO and the correct CH340 COM port. Paste the full fish finder code and click Upload. The CH340 driver must be installed for your PC to detect the board.
7
Test on the bench first
Before waterproofing, power up and hold your hand above the JSN-SR04T at various distances. The display should show a scrolling sonar screen with changing depth values. Verify the screen lights up with the splash screen on boot.
8
Mount in waterproof box
Drill a hole for the TFT display window on the lid, and a cable gland hole for the JSN sonar cable at the bottom. Mount the Arduino inside with standoffs. Seal all edges with silicone. Thread sonar cable through and waterproof the entry point.
Common issues & fixes
Screen stays black / blank
Check TFT CS, DC, RST pins are correct. Make sure the TFT module is a 5V-compatible version or uses a level shifter. Some modules only take 3.3V — check your module's datasheet.
Depth always shows max / "---"
No echo received. Point JSN-SR04T straight down. Make sure you're using the JSN-SR04T not HC-SR04. Check VCC and GND connections. Water must be calm and sensor must be fully submerged.
CH340 port not detected
You need the CH340 driver installed. Download from: sparfun.com/ch340 or search "CH340 driver". After installing, restart Arduino IDE and the COM port should appear.
Noisy or jumping depth readings
Increase the IIR filter coefficient in code from 0.72 to 0.85 for smoother readings. Also make sure sonar is pointing straight down at 90° — any angle causes inaccurate distance.
Testing fish detection
In a bucket of water, slowly move your hand at mid-depth while sensor is at top. The display should show fish arches and the header should flash red "FISH DETECTED". This validates detection is working before real use.
Mounting the sonar correctly
Mount the JSN-SR04T on the hull of a boat or on a pole, pointing straight down. Keep it at least 5cm below the waterline. The transducer face should be fully submerged and level for accurate readings.
