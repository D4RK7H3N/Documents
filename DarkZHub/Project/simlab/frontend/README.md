# SimLab frontend

## Adding custom 3D species models (.glb)

The 3D arena ships with procedural species only. To use a real model, set
`modelUrl` on a species in `src/species/registry.js` and place the `.glb`
under `public/models/`.

**License requirement:** any model file committed to this repository must be
redistributable — CC0, or CC-BY with attribution recorded next to the file
(author, license, source URL) in this README. Do not commit models with
unknown or non-commercial-only licenses.
